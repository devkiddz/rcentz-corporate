About the Project

Rcentz Corporate is the public-facing digital identity of Rcentz. It serves as the central point for introducing the company, communicating its capabilities, and connecting visitors to its wider ecosystem.

The website is maintained independently from Rcentz Systems, Rcentz Products, and the Rcentz API.

Technology Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* pnpm

Getting Started

Requirements

* Node.js
* pnpm

Installation

Clone the repository:

git clone https://github.com/devkiddz/rcentz-corporate.git
cd rcentz-corporate

Install dependencies:

pnpm install

Start the development server:

pnpm dev

Open http://localhost:3000 to view the website.

Project Structure

src/
  app/          Application routes and layouts
public/
  brands/       Official brand assets and media

Deployment

The project is connected to Vercel for continuous deployment.

Commits pushed to the configured production branch (main) trigger production deployment. Other branches can be used for preview deployments.
